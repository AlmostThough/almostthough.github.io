AlmostThough channel tools

A private tool that the owner of a few YouTube history channels uses to run their own channels. It is not a public service and nobody else can sign up or use it.

With the owner's Google sign-in it:

  • reads YouTube and YouTube Analytics statistics for the owner's own channels (views, watch time, traffic sources, impressions);
  • updates the owner's own videos (titles, descriptions, thumbnails, captions, publish dates).

It never accesses anyone else's account or data.
