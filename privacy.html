Privacy policy: AlmostThough channel tools

Last updated: 8 November 2026

Who uses this app

AlmostThough channel tools is a private tool. Only the owner of the AlmostThough YouTube channels signs in to it, with their own Google accounts. It is not offered to the public.

What data it accesses

Through the YouTube Data API and the YouTube Analytics and Reporting APIs it accesses, for the owner's own channels only:

  • channel and video statistics (views, watch time, traffic sources, impressions, audience reports);
  • video metadata (titles, descriptions, thumbnails, captions, publish dates), which it can also update.

It does not access any other person's account, channel or data.

How the data is used and stored

The data is used only to analyse and manage the owner's own channels. It is stored on the owner's computer and in the owner's private code repository. The owner analyses it with the help of an AI assistant (Anthropic's Claude). It is not sold, not used for advertising and not shared with anyone else.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

YouTube and Google terms

This app uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
